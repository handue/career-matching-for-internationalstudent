## 2026-09-28 — 프로젝트 시작

- 개인용 미국 채용 공고 분석 프로젝트 폴더와 Python 가상환경 생성.
- Ollama와 Qwen3-8B를 설치하고 가상 공고 한 개를 JSON으로 분석.
- 첫 실행에서 비자 스폰서십 불가 문구를 `unknown`으로 오분류했고,
  지침을 수정해 샘플에서는 `no`와 원문 근거를 확인.

## 2026-09-29 — 분류 예제 확장

- 비자 스폰서십 가능·불가·조건부·무언급 가상 공고를 준비.
- 모델이 학위 조건을 경력으로 오인하는 사례를 발견해 지침을 수정.
- 당시의 포괄적인 `sponsorship` 필드는 이후 제도별 분류를 위해 제거.

## 2026-09-30 — OPT 독립 분류

- 서비스 범위를 CPT, OPT, STEM OPT, H-1B, 취업 기반 영주권으로 조정.
- 일반 OPT 상태와 근거 문장을 별도 필드로 추가.
- 일반 비자 스폰서십 불가를 OPT 불가로 오인하고 STEM OPT 문장을
  일반 OPT 근거로 사용하는 오류를 발견.
- OPT 관련 원문 문장을 먼저 추리고, 모델이 그 문장만으로 판단하게 수정.
- 가상 공고 `yes`·`no`·`unknown` 및 혼합 사례에서 기대값 확인.

## 2026-10-01 — 샘플 정답표와 STEM OPT

- 다섯 제도의 긍정·부정·무언급·혼합 가상 공고와
  `samples/expected_statuses.json` 정답표 생성. 학습 데이터가 아닌 검증용.
- 모델이 원문 근거를 다르게 복사하는 실패를 확인해, 코드가 원문 문장을
  근거로 채우도록 변경.
- STEM OPT 상태와 근거를 일반 OPT와 별도 필드로 추가.
- 가상 공고 6개에서 두 항목의 기대 상태와 원문 근거를 확인.
- 현재 한계: 실제 공고 수집, 웹 화면, CPT·H-1B·영주권 분류는 미구현.
